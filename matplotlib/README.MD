# 📊 Matplotlib Practice

Hands-on practice notebooks covering the basics of data visualization using Matplotlib.

## 📁 Files
- `matplotlibbb.ipynb` — Covers line plots, bar charts, pie charts, scatter plots, subplots, and fill_between

## 🧠 Concepts Covered
- **Line Plot** — styling with color, linestyle, linewidth, markers
- **Bar Chart** — single & grouped bar charts
- **Pie Chart** — labels, explode, autopct, colors
- **Scatter Plot** — size, color, edgecolor, alpha
- **Subplots** — displaying multiple charts in a single figure using `subplot(rows, cols, index)`
- **Fill Between** — highlighting area between two lines on a plot

## 🔑 Key Takeaway
`subplot()` was the most useful concept — it lets you combine multiple visualizations into a single, organized figure instead of creating separate plots.
